# Meu Plano

> No longo prazo eu não perco.

App de celular para acompanhar um plano de 6 meses: rotina diária, metas, clientes e revisão semanal.

## Funções

- **Hoje**: lema em destaque, frase de disciplina do dia, contador de negócios abordados, rotina com horários, dinheiro do dia e lista de ideias "para depois".
- **Clientes**: funil simples (Abordado → Conversando → Orçamento enviado → Fechado), com valor mensal de cada cliente.
- **Metas**: metas de 30, 90 e 180 dias.
- **Domingo**: revisão semanal com 7 perguntas e alerta quando a semana fica abaixo da meta.
- **Progresso**: sequência de dias, patentes (Recruta → Coronel), totais e gráfico dos últimos 7 dias.
- **Ajustes**: lema, meta diária, rotina editável e backup dos dados.

## Como usar

Abra o link do GitHub Pages no navegador do celular e use "Adicionar à tela inicial".

Os dados ficam salvos no próprio celular. Use **Ajustes → Baixar backup** toda semana e guarde o arquivo em um lugar seguro.

## Tecnologia

HTML, CSS e JavaScript puro, num único arquivo (`index.html`), sem dependências.
